CONTRIBUTING.md and SECURITY.md are removed. Both are now served as
organization-wide defaults from lerna-labs/.github, and a repository's own copy
always took precedence over that default, so the local files left the org
versions unused here. README.md now carries the facts that were
repository-specific: the issue-intake conventions for this repository's role as
the platform's central tracker, and the OpenAPI lint, Postman regeneration, and
changelog guidance.
